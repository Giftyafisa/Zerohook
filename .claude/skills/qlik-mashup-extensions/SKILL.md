# Qlik Mashup & Extensions

## When to Use

- User wants to embed Qlik visualizations in a web app
- User asks about mashups, iframes, nebula.js, or Capability APIs
- User needs to build custom Qlik extensions
- User mentions web integration, embedding, or custom charts
- User wants single-object embedding or full app embedding

## Embedding Options Overview

| Method | Platform | Complexity | Use Case |
|---|---|---|---|
| **iframe** | Cloud + QSEoW | Low | Quick embed, full sheet/app |
| **nebula.js** | Cloud | Medium | Custom web apps, React/Angular |
| **Capability APIs** | QSEoW | Medium | Traditional mashups |
| **enigma.js** | Cloud + QSEoW | High | Direct engine communication |
| **Custom Extension** | Cloud + QSEoW | Medium | In-app custom viz |

## Qlik Cloud — iframe Embedding

The simplest way to embed Qlik Cloud content.

### Single Object Embed
```html
<iframe
  src="https://your-tenant.qlikcloud.com/single/?appid=APP_ID&obj=OBJECT_ID&opt=ctxmenu,currsel"
  style="border: none; width: 100%; height: 400px;"
></iframe>
```

### Full Sheet Embed
```html
<iframe
  src="https://your-tenant.qlikcloud.com/sense/app/APP_ID/sheet/SHEET_ID/state/analysis"
  style="border: none; width: 100%; height: 800px;"
></iframe>
```

### Web Integration ID (Required)

For cross-domain embedding, create a Web Integration ID:

1. **Management Console → Web integrations → Create**
2. Name: "My Portal"
3. Origins: `https://your-portal.com` (allowed domains)
4. Copy the generated ID

```html
<!-- Add to iframe URL -->
<iframe
  src="https://tenant.qlikcloud.com/single/?appid=APP_ID&obj=OBJ_ID&qlik-web-integration-id=WEB_INTEGRATION_ID"
  style="border: none; width: 100%; height: 400px;"
></iframe>
```

### iframe URL Parameters

| Parameter | Values | Description |
|---|---|---|
| `appid` | APP_ID | Target app |
| `obj` | OBJECT_ID | Specific visualization |
| `sheet` | SHEET_ID | Full sheet |
| `opt` | `ctxmenu,currsel` | Options: context menu, current selections |
| `select` | `field,value` | Pre-apply selections |
| `bookmark` | BOOKMARK_ID | Apply a bookmark |
| `theme` | THEME_ID | Custom theme |
| `language` | `en-US` | UI language |

### Pre-Applying Selections via URL
```html
<!-- Select Year=2024 and Region=North -->
<iframe
  src="https://tenant.qlikcloud.com/single/?appid=APP_ID&obj=OBJ_ID&select=Year,2024&select=Region,North"
></iframe>
```

## Qlik Cloud — nebula.js

nebula.js is the modern framework for embedding Qlik visualizations in custom web apps.

### Installation
```bash
npm install @nebula.js/stardust
```

### Basic Setup
```javascript
import { embed } from '@nebula.js/stardust';

const nebula = embed(app, {
  context: { theme: 'light' },
  types: [{
    name: 'barchart',
    load: () => import('@nebula.js/sn-bar-chart'),
  }],
});

// Render a visualization by ID
const viz = await nebula.render({
  element: document.getElementById('chart-container'),
  id: 'OBJECT_ID',
});
```

### Creating On-the-Fly Visualizations
```javascript
const viz = await nebula.render({
  element: document.getElementById('chart-container'),
  type: 'barchart',
  fields: ['Region', '=Sum(Sales)'],
});
```

### With React
```jsx
import { useElement, useLayout } from '@nebula.js/stardust';

function QlikChart({ app, objectId }) {
  const ref = useRef(null);

  useEffect(() => {
    if (!app || !ref.current) return;

    const nebula = embed(app, {
      types: [{ name: 'barchart', load: () => import('@nebula.js/sn-bar-chart') }],
    });

    nebula.render({ element: ref.current, id: objectId });

    return () => { /* cleanup */ };
  }, [app, objectId]);

  return <div ref={ref} style={{ height: '400px' }} />;
}
```

## QSEoW — Capability APIs

Traditional mashup approach for on-premise Qlik Sense.

### Mashup Template
```html
<!DOCTYPE html>
<html>
<head>
  <link rel="stylesheet" href="https://qlik-server/resources/autogenerated/qlik-styles.css">
  <script src="https://qlik-server/resources/assets/external/requirejs/require.js"></script>
</head>
<body>
  <div id="chart1" style="width: 100%; height: 400px;"></div>

  <script>
    var config = {
      host: 'qlik-server',
      prefix: '/',
      port: 443,
      isSecure: true,
    };

    require.config({
      baseUrl: (config.isSecure ? 'https://' : 'http://') + config.host +
               (config.port ? ':' + config.port : '') + config.prefix + 'resources',
    });

    require(['js/qlik'], function(qlik) {
      var app = qlik.openApp('APP_ID', config);
      app.getObject('chart1', 'OBJECT_ID');
    });
  </script>
</body>
</html>
```

### Common Capability API Methods

```javascript
// Open app
var app = qlik.openApp('APP_ID', config);

// Get visualization by ID
app.getObject('elementId', 'OBJECT_ID');

// Create session object (on-the-fly)
app.visualization.create('barchart', ['Region', '=Sum(Sales)'])
  .then(function(vis) {
    vis.show('elementId');
  });

// Apply selections
app.field('Year').selectValues([{qText: '2024'}], false, false);

// Clear selections
app.clearAll();

// Get variable value
app.variable.getContent('vCurrentYear', function(reply) {
  console.log(reply.qContent.qString);
});

// Destroy session
qlik.callRepository('/qrs/app/' + appId);
```

## enigma.js — Direct Engine Communication

For advanced use cases requiring direct Engine API access.

### Installation
```bash
npm install enigma.js ws
```

### Basic Connection (Qlik Cloud)
```javascript
import enigma from 'enigma.js';
import schema from 'enigma.js/schemas/12.936.0.json';

const session = enigma.create({
  schema,
  url: `wss://your-tenant.qlikcloud.com/app/APP_ID`,
  createSocket: url => new WebSocket(url, {
    headers: { Authorization: 'Bearer YOUR_API_KEY' },
  }),
});

const global = await session.open();
const app = await global.openDoc('APP_ID');

// Get layout of an object
const object = await app.getObject('OBJECT_ID');
const layout = await object.getLayout();
console.log(layout);

// Make selections
const field = await app.getField('Year');
await field.selectValues([{ qText: '2024', qIsNumeric: false }]);

await session.close();
```

## Custom Extensions

### Extension Structure
```
my-extension/
├── my-extension.qext        # Extension metadata
├── my-extension.js          # Main code
├── template.html            # HTML template (optional)
└── my-extension.css         # Styles (optional)
```

### .qext File
```json
{
  "name": "My Extension",
  "description": "Custom visualization",
  "type": "visualization",
  "version": "1.0.0",
  "icon": "bar-chart-horizontal",
  "author": "Your Name"
}
```

### Extension JavaScript (Paint API)
```javascript
define(['qlik', 'jquery'], function(qlik, $) {
  return {
    definition: {
      type: 'items',
      component: 'accordion',
      items: {
        dimensions: {
          uses: 'dimensions',
          min: 1,
          max: 2,
        },
        measures: {
          uses: 'measures',
          min: 1,
          max: 3,
        },
        settings: {
          uses: 'settings',
        },
      },
    },

    paint: function($element, layout) {
      var html = '<table>';

      layout.qHyperCube.qDataPages[0].qMatrix.forEach(function(row) {
        html += '<tr>';
        row.forEach(function(cell) {
          html += '<td>' + cell.qText + '</td>';
        });
        html += '</tr>';
      });

      html += '</table>';
      $element.html(html);
      return qlik.Promise.resolve();
    },
  };
});
```

### Installing Extensions

**Qlik Cloud:**
1. Management Console → Extensions → Upload
2. Upload .zip of the extension folder

**QSEoW:**
1. QMC → Extensions → Import
2. Or copy to: `C:\Qlik\Sense\Extensions\`

## Authentication for Embedded Content

### Qlik Cloud — JWT Authentication
```javascript
// For custom portals that need programmatic auth
const response = await fetch('https://tenant.qlikcloud.com/login/jwt-session', {
  method: 'POST',
  credentials: 'include',
  headers: {
    'Authorization': 'Bearer ' + jwtToken,
    'qlik-web-integration-id': WEB_INTEGRATION_ID,
  },
});
```

### QSEoW — Ticket API
```javascript
// Request a ticket for a user
const ticket = await fetch('https://qlik-server:4243/qps/ticket', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    UserDirectory: 'MYCOMPANY',
    UserId: 'john.doe',
  }),
  // With certificate auth
});

// Redirect user with ticket
window.location = `https://qlik-server/hub?qlikTicket=${ticket.Ticket}`;
```

## Best Practices

1. **Start with iframe** — Simplest, works everywhere, handles auth automatically
2. **Use nebula.js for modern apps** — Better control, React/Angular integration
3. **Cache app connections** — Don't open a new session per chart
4. **Handle selections globally** — One selection bar for all embedded objects
5. **Use themes** — Match embedded Qlik content to your portal's design
6. **Lazy-load visualizations** — Only render charts when visible (IntersectionObserver)
7. **Handle errors** — WebSocket disconnects, expired sessions, missing objects
